# BSys - The MSWB2S Build System!

Build this by using the provided Pre-built file from our [Releases](https://github.com/MSWB2S/BSys/releases)

Put it anywhere, add it to path, and run:
```bash
wbsys wbsys.ini build
```

In the WBSys Source Directory.
